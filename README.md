# Ecole Directe Plus

> A better EcoleDirecte (unaffiliated): more pleasant, functional, and improved experience.

This fork includes an experimental **ED+ Student Suite** on the `agent/edp-student-suite` branch. It adds a live weekly timetable, richer grade statistics (including median), persistent predicted grades, mock-brevet tracking, custom themes, local QCM practice, streaks and unlockable mini-games.

The Student Suite stores its extra user-created data locally in the browser. QCM corrections are only shown for questions whose correction is available to ED+ or was entered by the user; it does not attempt to reveal hidden school answers.

For the original project documentation, setup instructions, license, contribution guidelines and project history, see the upstream repository: https://github.com/Magic-Fish-Labs/Ecole-Directe-Plus
